Words on the next few pages

What these words mean

Nothing later uses a term that is not on this page.

API tokensometimes “API key”
A long password that a program uses instead of a person. It lets my code sign in to Jira as you, and read what you can read. It cannot be typed by a human at a login screen, and it can be cancelled at any time without changing your own password.
Scoped
A token that is limited to certain things — here, reading only. It is the only kind your Atlassian account can create, and it is the safer kind. I have already built the code to work with it.
Read-only
The token I am asking for can look at Jira and change nothing in it. Nothing I do can move a ticket, close an issue or notify anyone.
Function secret
Where the token goes to live afterwards: a locked box on the server, readable by the running code and by nobody through a browser. I put it there; you never have to.
Cloud ID
Jira’s internal number for your Atlassian site. You will never see or type it — my code looks it up. Mentioned only because it appears in the technical notes.

One rule, and it is the only rule

Never paste the token into a chat window — including mine. Anything typed in a chat is stored in that conversation. The token goes into a file, and I read the file. Page 5 is that file.

Create the token

In your browser, signed in to Atlassian as yourself. About three minutes.

1
Go to id.atlassian.com/manage-profile/security/api-tokens You land on a page headed API tokens, probably with an empty list.
2
Press the button that creates a token. Atlassian keeps changing this wording — it may say Create API token, or offer you a choice between a plain one and one “with scopes”. If you are offered the choice, take the one with scopes. It is the only kind your account can make. A small form appears asking for a name.
3
Name it nphiescore and set the longest expiry it offers you. The name is only a label so you can recognise it later and cancel it if you ever want to.
4
If it asks which app, choose Jira. If it then asks which permissions, tick the two that mention reading work and reading user — usually shown as read:jira-work and read:jira-user. Nothing on that list should say write, manage or delete. If you ticked one by accident, untick it — I do not need it.
5
Create it, then copy the token. A long string of letters and numbers appears.

This is the trap, and everyone hits it once

The token is shown exactly once. Close that window without copying it and it is gone for good — there is no “show it again”. You are not locked out if that happens: delete the token you just made and create another. It costs two minutes, not a support ticket.

Put it in the file

Three lines. I will have the file open and waiting, so you are filling in blanks, not creating anything.

JIRA_BASE_URL
Your Jira web address, as far as .net and no further. Looks like https://something.atlassian.net — copy it out of your browser’s address bar while Jira is open, then delete everything after .net.
JIRA_EMAIL
The email address you sign in to Atlassian with. Not a colleague’s, and not necessarily the one you use for everything else — it must be the account that made the token on the previous page.
JIRA_API_TOKEN
The long string you copied. Paste it whole — no spaces before or after, no quotation marks.

The mistake this step invites

Pasting the whole Jira page address into the first box — the one with /jira/software/projects/… on the end. The code checks for this and refuses with a clear message rather than failing strangely, so it is recoverable — but it costs a round trip. Stop at .net.
