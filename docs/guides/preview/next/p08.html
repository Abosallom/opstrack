Switch on the padlock

One tick box — but only after GitHub is ready, and it will not tell you.
GitHub makes a security certificate for your domain automatically. It just takes a while.

On GitHub, in Settings → Pages, there is a tick box called Enforce HTTPS. It is what puts the padlock in the address bar and stops anyone reaching the site without one.

Good news — the waiting is already over

Checked on 21 August 2026: GitHub reports the certificate for nphiescore.com as approved. So you can tick Enforce HTTPS straight away; the caution below no longer applies to you, and is kept only in case the domain is ever re-pointed.

The rule that made it worth waiting

If the tick box is greyed out, or the page still says it is provisioning, leave it alone. Ticking it before the certificate exists does not make the site less secure — it makes the site unreachable, for everyone, until the certificate arrives. Check back the next day.

How you will know it is ready

The provisioning message disappears and the tick box becomes clickable. Tick it, then visit https://nphiescore.com and look for the padlock next to the address. That is the last piece of the move.
