Create the accounts

Part two. Stay at the keyboard for this one — it prints something you cannot get back.
They claim it at the sign-in screen, using the “First time here?” link.
1
Get a temporary key. Sign in at https://nphiescore.com/ in Chrome — it must be that address, because browsers keep this per web address. Then press ⌥⌘I to open the developer tools, click the Console tab, paste this line and press Enter:
const k = 'sb-lrysgpbkmuqgzsjesfkr-auth-token' JSON.parse(localStorage.getItem(k)).access_token
A long string in quotes. Copy it, without the quotes. It is not your password, it expires in about an hour, and that is plenty.
2
Run it for real. In Terminal, paste these four lines, putting your key between the quotes:
cd /Users/aziz/Claude/nphiescore set -a; . ./.env.local; . ./.env; set +a export ADMIN_ACCESS_TOKEN='paste-your-key-here' node scripts/provision-people.mjs --apply

If you see usage: apply [-a magic]

The command arrived split in two: --apply became -- on one line and apply on the next, and macOS has its own unrelated apply command that then complained. Nothing ran. Check the last line reads --apply with no break in it before pressing Enter, and run it again.

The sixteen codes print once and exist nowhere else afterwards

Not in a file, not in the database, not recoverable by anyone. Copy them out of the Terminal window before you close it. Lose one and that account must be scrapped and redone. Hand each person theirs directly. Never paste a code — or the key from step 1 — into a chat. If one ever does end up somewhere it should not, sign out of the app: that ends the session it belongs to.
